I've Made 111 One-Button Mini-Games into a Collection (Out of 200 Created)

abagames.itch.io

This is a WarioWare-style game where you play quick one-button action mini-games in succession. You earn stars based on successful completions and can unlock new games. Higher difficulties like Hard and Expert offer more stars but are more challenging. Try to unlock all 111 games!

You can play directly in your browser on PC or smartphone. If you don't like certain games, you can click their icon and "Ban" them to prevent them from appearing. Create your own preferred deck of mini-games!

If you're unsure about a game's rules, click its icon and select "Play" to practice that game without time limits. Don't get discouraged by puzzling rules!

After steadily creating games, I've now made 200 one-button games in total.

asahi-net.or.jp

After making 200 games, the one-button limitation no longer feels like a constraint. It becomes natural to think about controls, actions, fields, and risk-reward systems that work well with just one button. Being unable to use conventional controls like directional keys naturally leads to slightly unusual game designs, which can actually make ideation easier in some ways.

I've accumulated considerable knowledge about one-button game controls, and I can even use this knowledge with LLMs to assist in game generation. Lately, it almost feels like I'm creating games through muscle memory as a routine.

Still, the final adjustments to parameters and rules to make games entertaining feels like craftsman's work and remains enjoyable. I want to continue making games while treasuring this sense of balance adjustment, which feels like a crucial skill to cultivate.
